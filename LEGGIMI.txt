RIORDINA DOCK
=============

🇮🇹 ITALIANO
1. Apri l'app Terminale (⌘ + Spazio, scrivi "Terminale").
2. Scrivi:  bash   (con uno spazio dopo)
3. Trascina dentro il Terminale il file "Installa Riordina Dock.command".
4. Premi Invio.
L'app viene compilata (serve Xcode), messa in Applicazioni e aperta.
La trovi nella barra dei menu in alto, vicino all'orologio.

🇬🇧 ENGLISH
1. Open the Terminal app (⌘ + Space, type "Terminal").
2. Type:  bash   (followed by a space)
3. Drag the file "Installa Riordina Dock.command" into the Terminal window.
4. Press Return.
The app is built (Xcode required), copied to Applications and launched.
You'll find it in the menu bar at the top, next to the clock.

Backup / Copia di sicurezza: ~/Library/Application Support/Riordina Dock/


RIORDINA DOCK — how to install (English)
========================================

1. Open Terminal (Spotlight: ⌘ + Space, type "Terminal").
2. Type:  bash   (followed by a space)
3. Drag the file "Installa Riordina Dock.command" into the Terminal window.
4. Press Return.

The app is built, copied to Applications and launched.
Look for the Dock icon in the menu bar, next to the clock.
